Validation rules

What one row of the final dataset should look like, written as rules:

# Rule Why
1 ticker + year + quarter is unique one row per REIT per quarter
2 every Nareit ticker is found in the SEC ticker file otherwise we have no financials for it
3 every REIT-quarter has SEC revenue failed join or a tag we did not pull
4 every REIT-quarter has a press release missing 8-K or no Exhibit 99.1
5 the quarter the LLM read matches the quarter from the filing date catches a wrong release or a misread
6 occupancy is between 80 and 100 retail REITs do not run below ~80%; above 100 is impossible
7 same-property NOI growth is between -15 and +15 percent anything outside that is almost surely a misread (e.g. year-to-date or a typo)
8 FFO per share is between $0 and $5 for a quarter a negative or huge FFO usually means the wrong line was read (Simon’s is really about $3.20, so the cap is $5)
8b FFO is at least half of core FFO a much smaller “FFO” usually means the model grabbed net income per share instead
9 revenue is positive a derived Q4 (full year minus Q1-Q3) can go negative if a tag changed mid-year
10 liabilities are less than assets negative equity is possible but worth a look
11 quarterly stock return is between -40% and +40% bigger moves are rare; check for a split or bad price
12 property_type is one of the allowed categories invalid category
13 each LLM number actually appears in the press release text the model should copy numbers, not invent them

Validation table

The rows that break each rule. An empty result for a rule means every row passed.

flag = function(data, rule, column, value) {
  data |>
    transmute(rule = rule, ticker,
              quarter = if ("quarter_label" %in% names(data)) quarter_label else NA_character_,
              column = column, value = as.character({{ value }}))
}

v[[6]] = df |> filter(!is.na(occupancy_pct), occupancy_pct < 80 | occupancy_pct > 100) |>
  flag("6 occupancy out of range", "occupancy_pct", occupancy_pct)

v[[7]] = df |> filter(!is.na(same_property_noi_growth_pct), abs(same_property_noi_growth_pct) > 15) |>
  flag("7 SP NOI growth out of range", "same_property_noi_growth_pct", same_property_noi_growth_pct)

v[[8]] = df |> filter(!is.na(ffo_per_share), ffo_per_share <= 0 | ffo_per_share > 5) |>

v[[14]] = df |> filter(!is.na(ffo_per_share), !is.na(core_ffo_per_share), ffo_per_share < 0.5 * core_ffo_per_share) |>
  flag("8b FFO much lower than core FFO", "ffo_per_share", paste0(ffo_per_share, " vs core ", core_ffo_per_share))

v[[9]] = df |> filter(!is.na(revenue_mm), revenue_mm <= 0) |>
  flag("9 revenue not positive", "revenue_mm", revenue_mm)

v[[10]] = df |> filter(!is.na(liabilities_to_assets), liabilities_to_assets >= 1) |>
  flag("10 liabilities >= assets", "liabilities_to_assets", round(liabilities_to_assets, 3))

v[[11]] = df |> filter(!is.na(total_return_q_pct), abs(total_return_q_pct) > 40) |>
  flag("11 quarterly return out of range", "total_return_q_pct", round(total_return_q_pct, 1))

allowed = c("grocery_anchored_center", "open_air_center", "mall_outlet", "net_lease", "mixed")
v[[12]] = df |> filter(!is.na(property_type), !property_type %in% allowed) |>

Rule 13 is the check on the LLM. For each number the model returned, we look for that number written in the press release text (as 96.6, 96.60, or $0.47). If we cannot find it, the model may have calculated or made it up, and the row goes in the table to check by hand.

num_in_text = function(x, txt) {
  if (is.na(x)) return(NA)
  forms = unique(c(format(x, nsmall = 1, trim = TRUE), format(x, nsmall = 2, trim = TRUE),
                   as.character(x), as.character(abs(x))))
  any(stringr::str_detect(txt, stringr::fixed(forms)))
}

grounding = pr |>
  filter(file.exists(file)) |>
  rowwise() |>
  mutate(
    txt = paste(readLines(file, warn = FALSE), collapse = " "),
    occupancy_found = num_in_text(occupancy_pct, txt),
    sp_noi_found    = num_in_text(same_property_noi_growth_pct, txt),
    ffo_found       = num_in_text(ffo_per_share, txt)
  ) |>
  ungroup() |>
  select(-txt) |>
  mutate(quarter_label = paste0(year, " Q", quarter))

v[[13]] = bind_rows(
  grounding |> filter(occupancy_found == FALSE) |> flag("13 LLM value not in text", "occupancy_pct", occupancy_pct),
  grounding |> filter(sp_noi_found == FALSE)    |> flag("13 LLM value not in text", "same_property_noi_growth_pct", same_property_noi_growth_pct),
  grounding |> filter(ffo_found == FALSE)       |> flag("13 LLM value not in text", "ffo_per_share", ffo_per_share)
)

same_property_noi_growth_pct and rent_spread_pct are missing for most net-lease REITs on purpose: those companies do not report same-property NOI or leasing spreads (they report rent recapture or AFFO instead). That is a real difference between business models, not a data error.
